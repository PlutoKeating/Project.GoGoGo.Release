## 中文

### 更清楚的下载与更新页面
- 更新说明现在完整显示标题、列表、表格、引用和代码，不再出现未渲染的 Markdown 标记。
- Android 与 iOS 使用独立的圆角下载按钮；清单和校验文件不再混在用户下载区。
- 最新版本卡片更加简洁，页脚按应用入口、协议与联系信息分栏，手机上也能轻松阅读。

### Android 安装包
- 本次提供独立签名的 Android APK，可从本页 Android 按钮下载。支持 Android 6.0 及以上系统。修复了 APP 启动、前后台监听和原生样式问题。
- 首次安装时按系统提示允许所用浏览器或文件管理器安装应用。以后使用同一签名的新版覆盖安装，无需清空私人档案。
- 已进行安装包签名与内容校验及 Android 模拟器安装启动检查；不同品牌真机的表现仍需反馈。

### iOS 状态
- iOS 安装包尚未发布，仍需 Apple 签名与分发配置。请先使用网页版；不会提供无法安装的占位文件。

## English

### A clearer download and update experience
- Release notes now render headings, lists, tables, quotes and code instead of exposing raw Markdown.
- Android and iOS have separate rounded download buttons. Technical manifests and checksums no longer clutter the download area.
- The latest-version card is concise, and footer links are grouped for comfortable mobile reading.

### Android installer
- This release includes an independently signed Android APK, available through the Android download button. Android 6.0 or later is supported. App startup, lifecycle handling and native layout issues were fixed.
- Follow Android's prompt to allow installation from your browser or file manager. Future builds use the same signing identity, so you can update in place without clearing private profiles.
- APK signing/content checks and an Android emulator installation/startup check were performed. Feedback from physical devices is still needed.

### iOS status
- An iOS installer is not yet published; Apple signing and distribution configuration are still required. Use the Web app for now. No non-installable placeholder is provided.
